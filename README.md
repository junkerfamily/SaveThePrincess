# Saving Sabrina

Princess Sabrina is locked at the top of Thornspire Tower. Climb five floors of push-the-crate puzzles to save her.

- Push crates, fill water with crates to make bridges, smash cracked rocks with the hammer, block gargoyle glares, and hold gates open with pressure plates.
- Arrows / WASD to move, Space to swing the hammer, Z to undo, R to restart. On phones, use the on-screen pad or swipe.

## Files
- `index.html`: page and styles
- `logic.js`: game rules (no DOM, so it can run in Node)
- `levels.js`: the five floors, drawn as text maps (legend at the top of `logic.js`)
- `game.js`: drawing, sound, input and screens
